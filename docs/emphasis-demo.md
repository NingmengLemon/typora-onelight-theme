# 着重标记样式演示

这个文档演示了新的着重标记样式，它们适配了亮色风格的标题样式。

## 四种着重标记效果

### 1. 加粗 - 适配H6样式
**这是加粗文本** - 采用多色彩渐变效果

普通文本中的 **加粗强调** 会显示美丽的彩色渐变动画。

### 2. 高亮 - 适配H4样式  
==这是高亮文本== - 采用"落日熔金"渐变主题

普通段落中的 ==重要高亮== 内容会有动感的渐变流动效果。

### 3. 斜体 - 适配H5样式
*这是斜体文本* - 采用"热带岛屿"渐变主题

文档中的 *强调斜体* 文字会展现热带风情的色彩变化。

### 4. 引用 - 适配H3样式
`这是内联代码` - 采用淡雅背景渐变

代码片段 `function highlight()` 会有柔和的背景流动效果。

## 组合效果测试

你可以组合使用这些样式：
- **加粗** 和 *斜体* 可以 ==高亮== 显示 `代码片段`
- 在同一段落中：**重要内容** 配合 ==关键信息== 和 `技术术语`

## 动画效果说明

所有着重标记都包含以下特性：
1. **流动的渐变动画** - 持续的颜色流动效果
2. **悬浮交互** - 鼠标悬停时的特殊效果
3. **色彩搭配** - 与亮色主题完美融合
4. **性能优化** - 平滑的动画过渡

> 注意：这些样式专门为 onelight 亮色主题设计，与 title-colorful.css 的彩色标题样式保持一致的视觉风格。
